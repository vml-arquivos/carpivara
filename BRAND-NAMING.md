# Naming

"Carpivara" NÃO é recomendado como marca comercial: já existem serviços brasileiros de consulta veicular usando o mesmo nome/variações no mesmo segmento.

Nome de trabalho adotado neste pacote: **Carpivara**.
Racional: mantém a sonoridade/memória do conceito original e a associação "car", mas é suficientemente diferente para desenvolvimento provisório.

Antes do lançamento público: fazer busca de anterioridade no INPI, validar domínio e redes sociais e realizar revisão jurídica. A ausência em uma busca web não garante disponibilidade de marca.
